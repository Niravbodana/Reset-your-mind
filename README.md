# RIZN

Personalized daily motivation — web preview now, mobile app coming soon.

## Quick start

```bash
cd saathly
npm install
npm run dev
```

Open http://localhost:3000

If git pull fails due to local changes:
```bash
git reset --hard origin/cursor/saathly-website-9e8a
```
