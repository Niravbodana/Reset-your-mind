# RIZN

**Your name. Your nudge. Your rise.**

Black-laser daily motivation system for busy minds — finance, health, love, career.

## Run

```bash
cd saathly
npm install
npm run dev
```

Docker:

```bash
cd saathly
docker compose up --build
```

→ http://localhost:3000
